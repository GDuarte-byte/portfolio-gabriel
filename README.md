## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `portfolio-gabriel`.
2. Envie os arquivos `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde alguns minutos. O GitHub mostrará o endereço publicado.

## Personalização rápida

- Textos e links: `index.html`
- Cores e aparência: início do arquivo `style.css`
- Textos animados: lista `roles` no arquivo `script.js`
